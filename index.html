About

From server owner
to developer

Minecraft got me into coding. I wanted my servers to do things nobody else's could, so I picked up Skript — and then Java — and figured out how to make it happen.

I've owned multiple servers along the way. My best one peaked at 54 players online at once. But running a server means juggling six things at the same time, and I learned something useful about myself: the part I love is the building, not the managing. So I quit owning servers and kept developing for them.

These days I build plugins and Discord bots for real communities, and web projects like this site. Based in the Netherlands.
