What I've built

This is a showcase of my work in minecraft development.

PrimalMinesCore

This is my prized possession. This specific plugin held my entire minecraft server together! It consists of a TON of modules each having a very important use in my server. In the cards below i explain every module.

Fortune

This module handles the most important part of any mining server. The compression. It did this perfectly allowing for high fortune and multipliers amounts and it could keep up with no problems. It also had a custom enchant: Trench. Which made you mine more than one block based on the level of it.

Levels

The name pretty much speaks for itself but this module handles the gaining exp and leveling up. You can get exp multi by prestiging same as fortune. I also wrote a skript kinda like an addon where you can have temporary exp multipliers.

Skills

This part of the module is your average skills plugin. You gain skill xp you level up and get level experience and money. It has 5 base skills: Combat, Mining, Bosses, Experience and taming.

Pets

This is my favorite module. It has over 130 custom pets each with its own abilities and stat boosts. They're kind of like the hypixel skyblock pets in terms of your pet following you around and the way the lore is built.

Holograms

I added this module because i hated the modern hologram plugins (Fancyholograms, decentholograms) It does everything both do but combined. You can have blocks scaling holograms being a billboard etc.

Crates

The crates also got added because modern crates plugins suck. Excellent crates is good but takes years to set up. This one works out of the box. Set up rewards and chances with a ui easily and more.

Shops

The shops module got added because i didn't like using the shopkeepers plugin. The way it works is you have categories where you buy tools and armor and such. Behind the scenes you have a full admin menu where you can easily edit shops to your liking.

Talisman

The talisman module is kinda like the pets module. You get stat boosts from having certain talisman in your bag. You start out with 3 slots and can have a maximum of 9. There are 13 talisman and they give mining, combat and pet xp boosters.

Mining events

The mining event triggers every hour in non-prestige worlds where you have to mine as much of a block as you can in order to get first place. The top 3 get rewarded with keys and money. Each event lasts 15 minutes.

Autogear

Autogear got added because i got tired of having to do custom lore for each piece of gear. It was so annoying and time wasting. So now you open the menu configure the name, color and enchants and voila you have a full armor set(s)! It works with armor swords and pickaxes but also custom items!

Quests

I kind of neglected this module but the idea was weekly quests which need to be configured by you. You could have combat, bosses or mining related quests and you decide what block they'd need to mine and how much of it. This all works but i disabled it because i had no real use for it on my server.

Gemstones

This module is an addon to the fortune module. You mine blocks and have a chance to find a gemstone. These can then be sold to the merchant but some were used in secret trades. Each dimension had its own gemstones but the amount varied. I think there were about 5-9 gemstones in each dimension

  • Server: PrimalMines

Playershops

The playershops plugin is an easy way to have your players create their own shops. It uses my hologram plugin to display the text above. It also features a transaction log which you can connect to your discord. It has the option to blacklist a world so you dont get your spawn world filled with shops. Players can add stock add items and admins can see every shop and its contents.


  • Java
  • Server: FerruhSMP Discord

Claims

This plugin does everything other claim plugins do but better. You can trust untrust, ban unban, promote demote players. It features a settings menu where you can edit everything everyone can do on your claim. You can edit every single member's permission. You can also edit environment settings like creeper explosions, fire spread and more!


  • Java
  • Server: FerruhSMP Discord

Gens

This plugin was built for a gen server it features upgradable generators, a genshop virtual item stacking sell wands and more. You could stack generators shift + right click to instantly upgrade them. Sell your stash using /sell view your stash. It has a bunch of placeholders meaning you can use them to build stuff with them using skript.


  • Java
  • Skript

Boss Slayers

This skript is one of my favorites. A whole entire slayer system. It uses mythicmobs for the bosses and skript for everything else. You can level up your slayers to get some cool rewards. Drop rare drops from bosses which had entire loot tables. Each boss had its own OP pet you could drop. You could also drop their signature weapon


  • Skript
  • Mythic Mobs (dependency)
  • Server: PrimalMines

Forge

The forge was an addon to the slayers. Using the shards you drop from each boss you can craft armor weapons pets and more. It wasn't really optimised for speed though since you have to manually run a command to add an item to the forge. It worked fine though and i really like it!
